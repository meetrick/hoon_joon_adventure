행궁동 어드벤쳐 웹 게임입니다.

## Play

GitHub Pages 배포 후 아래 주소에서 플레이할 수 있습니다.

https://meetrick.github.io/hoon_joon_adventure/

## Deploy

이 저장소는 GitHub Actions로 GitHub Pages에 배포됩니다.

1. GitHub 저장소의 **Settings > Pages**로 이동합니다.
2. **Build and deployment > Source**를 **GitHub Actions**로 선택합니다.
3. `main` 브랜치에 푸시하거나 Actions 탭에서 **Deploy game to GitHub Pages** 워크플로를 수동 실행합니다.
